# One Star for Monday

A one-star review of Monday, written as though Monday were a
restaurant — one line of plain text, 23 words:

> Waited an hour for a table, the waiter brought cold coffee, and the
> bill came before the food. One star. Monday, never again.

`main.py` writes that line to `/output/entry.txt` (or the directory
named by `MAKEFUN_OUTPUT_DIR`). It checks the line first: one line,
1–25 words, 1–180 characters, matching the competition's gate. No
network, no randomness: every run writes identical bytes.
